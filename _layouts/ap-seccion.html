--- layout: default --- {%- comment -%} Página de sección: encabezado propio (antetitulo, título, bajada y cifras), cuerpo a una columna ancha y, si la página lo pide, un riel lateral con el índice de la página y los datos del autor. No se pisa _layouts/single.html a propósito: así las entradas del blog siguen mostrándose como las saca el tema y solo estas páginas usan esta plantilla. Para volver atrás, basta con poner layout: single en el front matter de la página. Qué lee del front matter: icono nombre del icono del antetitulo (_data/apuromafo_iconos.yml) antetitulo texto chico sobre el título bajada una o dos frases, en Markdown cifras lista de {valor, etiqueta}, solo con datos reales filtro true para poner la barra de filtros encima de las fichas toc true para el índice "en esta página" en el riel autor true para la tarjeta del autor (en el riel, o al pie si la página no lleva riel) {%- endcomment -%} {%- comment -%} El riel se dibuja solo si la página pide índice (toc: true). El autor va al riel cuando hay riel, y al pie del contenido cuando no: en las páginas de fichas (Red Team, Programación, Herramientas) y en el índice, la numeración de las fichas y la barra de filtros ya cumplen ese papel, y el ancho completo se aprovecha mejor para leerlas. {%- endcomment -%} {%- assign apu_riel = false -%} {%- if page.toc -%}{%- assign apu_riel = true -%}{%- endif -%}
